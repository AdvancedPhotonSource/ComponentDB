# Import Tool
- Created import mechanism to support creating CDB items contained in Excel spreadsheets including common import wizard view and import helper framework.
  - Added mechanism for downloading empty template spreadsheet.
  - Added validation that input spreadsheet has expected number of columns.
  - Added mechanism for validating column length for spreadsheet text columns.
  - Added mechanism for optionally ignoring duplicates for a given domain.
  - Added support for spreadsheet columns that reference other CDB items by ID or name.
  - Added support for parsing hierarchical parent/child relationships from input spreadsheet.
  - Added optional tree view to import wizard validation tab to display hierarchical items (e.g., machine domain).
  - Allow user to select a sheet within spreadsheet file for import.
  - Added support for auto-naming of inventory units (cable and component).
  - Allow multiple import spreadsheet formats for a given domain.
- Created pre-processing Python scripts to convert cable data collection excel workbook to official CDB import spreadsheet formats for sources, cable catalog, cable designs, and cable inventory.
  - Add validation mode to pre-import scripts to identify data issues.
- Enabled and customized import framework for source domain.

- Enabled and customized import framework for cable catalog domain.
