# Host a REST API from Java Payara (Glassfish) Server
- Initial Functionality to support the Mobile App @AdvancedPhotonSource/componentdb-mobile.
- Ability to execute same code when performing edits to data as is executed in the portal.
- Utilizes Swagger OpenAPI standard to allow generation of client API in any language.
  - NOTE: Currently additional code is required for authentication.
  - Can be found at cdbHost/cdb-root/__api/openapi.json__
- REST Functionality
  - Ability to authenticate using REST 
  - Item Functionality
    - Fetch items by domain
    - Fetch top level locations
    - Fetch child locations
    - Add log entry
    - Update item details
    - Update location
    - Upload Image
    - Fetch item status
    - Fetch favorite items
    - etc
  - Users Functionality
    - Fetch all
    - Fetch by username
  - Property Type Functionality
    - Fetch all types
    - Fetch inventory status property type
- Support logging of REST API events.
