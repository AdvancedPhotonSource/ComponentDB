This release simplifies the process of importing kabel workbook data to production, and adds new features for managing, accessing, and exporting cable plant information. It also includes more lazy data models which will improve performance and reduce server load with more clients and more data. New command line interfaces will make it easier to quickly read and update many records in CDB using CSV files. Finally, more tests and bug fixes are included in the release to improve overall reliability and performance of the application.

# Cable
- Support for displaying and setting assigned inventory and installation status in cable design domain detail, edit, and list views
- Import script changes to generate a single excel output file with tabs for each CDB import sheet (sources, cable types, cable designs) in a single script execution, new tab in output workbook for connector types, new tab in output workbook for cable catalog connectors, note/comment handling, add cable connector information to cable design output sheet if specified for cable type, new CDB apis for connector type and cable catalog connector information, new output workbook tabs for summary/debug/error/validation information.
- Advanced filter display mode for cable designs to filter by endpoint device ancestors
- Import script handling column name changes and header validation to reflect kabel workbook changes 
- Add columns to CDB cable design pull list extract format for penetration and rack on each cable end
- Add optional rack/location columns to cable design list view
- Enhance portal's cable design wizard for manually creating cables to allow specifying device port and cable connector, clean up cable wizard integration from machine design tree view
- Support for moving machine design items to trash via the import/delete spreadsheet mechanism
# Lazy Data Models
- Add lazy data model for additional domains.
  - Catalog, Cable Catalog, Cable Inventory. 
- Add lazy tree for location tree list. 
- Integrate lazy data model with list display modes. 
# CLI
- New ENV variable to specify path of CDB configuration file.
- CSV input is user friendly in tty stdin mode with a prompt on expected format and other enhancements such as empty to row to finish and no skipping of header. 
- Each edit command has a flag that can be added to add a log to item of the change made by CLI. 
- Add conda recipes for publishing the API + CLI from pypi into a conda repo. 
- CSV driven commands 
  - add-document-file: Create a document property 
  - add-document-property: Create a Property with an http link handler to item. 
  - create-location: Creates a new location with id, qr_id, name,...
  - set-item-details: Update details such as description serial number of an item
  - set-item-location: Set new location for single or multiple items.
  - set-item-log-by-id: Add a log entry for an item. 
  - set-machine-install-state Update install state of assigned item on machine design to planned/installed. 
  - set-parent-location: Move a location such as a pallet to a new location. 
  - set-qr-id-by-id: Assigns QR Ids to a set of Item IDs.
  - update-hierarchy: Update item assembly assignments. 
- get-catalog-items-by-name: Gets given field(s) and inventory item(s) for a given catalog item. 
- get-location-id-by-name: Gets the corresponding ID for a location name
- get-properties: Inspects CDB for inventory with the selected property name and outputs a CSV
  of the current values in CDB. 
- set-item-status-by-id: Updates item status. 
- cdb-log-to-mqtt: Convert cdb system log to mqtt by periodically downloading it.
