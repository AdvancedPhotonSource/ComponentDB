# General

* Added a back to tree list button on machine design view page. This will take user to machine hiearchy and higlight the element.

# Search

* Property values are now included in search results, matching on value, tag, and markdown text.
  * Word order independent matching — each search word is matched independently.
  * Shortened match descriptions showing a snippet around the matched words rather than the full field.
  * Result label includes the owning item, property type, value, and tag.
  * Results link to the property on its parent item. (See Property Permalinks below)
* IOCs and applications items are now searchable from the search page and the API.
  * Dedicated IOC search stored procedure.
* New search display settings for IOC items, application items, and property values.

# Property Permalinks

* Copy permalink action button for any property value.
* Short permalink url that resolves the owning item and opens the property dialog on page load.
  * Markdown properties open in the markdown dialog, others in a new read only property details dialog.
  * Permalink is validated against the item in the url; a mismatched property reports the item it belongs to.
* Property value search results use the same permalink redirect.

# IOC

* IOC instructions moved to the top level of the IOC details page and rendered inline.
  * Toggleable panel
  * Edit action opens the instructions directly in edit mode for users with write access.
  * Full screen action for read only users.
  * Copy permalink action for the IOC instructions.
* IOC metadata property type is created with the markdown handler attached.

# API

* Ability to attach a file to an existing log entry.
* Ability to download a log attachment, preserving the original file name.
* Attachment list exposed when fetching item logs.
* IOC and application results added to the entity search API.
* Tests for log attachment upload and download.

# Other

* Migrated the python client to the latest openapi generator (7.24.0).
  * Pydantic based models; removed the `six` dependency.
  * Pinned `urllib3`, `python-dateutil`, `pydantic`, and `typing-extensions` in setup and conda recipes.
  * Updated authentication and api exception parsing in `CdbApiFactory`.
* Updated jackson, swagger, snakeyaml, and log4j (2.26.0) libraries in the portal.
  * Resolve XmlTransient fields being serialized into api json responses after the jackson upgrade.
* Add a prepare release script that bumps the version everywhere it appears and scaffolds release notes.

# Bug Fixes

* Adding a log entry via API now returns the created log entry with its id.
* Resolve issue where a property type handler could not be attached to a newly created property type.
* Resolve missing null check for property type metadata when loading an item.
