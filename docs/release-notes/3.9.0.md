# Domain Navigation

To accommodate the new cable features described below, the buttons used for domain navigation are changed to drop down menu buttons labeled "Catalog", "Inventory", and "Design".  The "Browse" and "MAARC" buttons are unchanged.  

The "Catalog" button menu items include options "Component" and "Cable Type".  Selecting "Component" displays the previously existing component catalog.  Selecting "Cable Type" displays the new cable type catalog, described in more detail below.

The "Inventory" button menu items include "Component" and "Cable".  Selecting "Component" displays the previously existing component inventory listing.  Selecting "Cable" displays the new cable inventory listing, described in more detail below.

The "Design" button menu items include "Machine" and "Cable".  Selecting "Machine" displays the previously existing machine design hierarchy view.  Selecting "Cable" displays the new cable design list view, described in more detail below.

# Cable

This release includes the first set of features for cable plant data management.  Three new domains are added: Cable Type Catalog, Cable Inventory, and Cable Design.  Initial features for each new domain are described in more detail below.

## Cable Type Catalog

The previously existing component catalog defines the various types of components to be used in the system.  Similarly, the new cable type catalog defines the different types of cables that will be used.  Each cable type catalog entry includes a name and part number.  The combination of these two attributes uniquely identifies cable types.  Other optional properties include: Description, Manufacturer, Technical System, URL (product specs), and physical properties such as Diameter, Weight, number of Conductors, Insulation type, Jacket Color, Voltage Rating, Fire Load, Heat Limit, and Bend Radius.

To navigate to the cable type catalog, select "Cable Type" from the "Catalog" menu button at the top left of the main CDB portal view.

Use the "Add" button at the top of the cable type catalog listing to create a new cable type catalog entry.  Specify core properties like Name, Part Number, Description, and Technical System on the add dialog.  After clicking "Save", the view for the new catalog entry is displayed.  You can also navigate to the page for a particular catalog entry by selecting it from the catalog listing page.  Optional properties are specified on the view for the new catalog entry.

Just as for the component catalog, the cable type catalog view for a particular entry also includes an image gallery, log entries, user-defined properties, and acquisition sources.  A new section "Connectors" facilitates specification of the connectors provided by the cable type.

The "Import" button at the top left of the cable type catalog listing allows cable type entries to be imported in bulk from a standard Excel spreadsheet format (.xlsx file).  The button opens a wizard whose first tab is used to select the file to import.  Selecting "Next Step" on that tab displays a table for reviewing the cable type entries found in the spreadsheet.  Invalid data are flagged in the rightmost 2 columns of the table, and must be fixed before the spreadsheet can be imported (after selecting "Cancel" to stop the import process).  Selecting "Next Step" on the review tab imports the data, creating a new cable type catalog entry for each row in the spreadsheet.

## Cable Inventory

The cable inventory domain is analogous to the previously existing component inventory mechanism.  It includes the units of inventory for each cable type catalog entry.  Inventory units might be in storage, or installed within the system.  The cable inventory domain has not yet been fully developed in this release, as we are in the process of defining the appropriate properties and desired features.

Currently, the core properties for a cable inventory unit include Name, QR ID, the corresponding cable type catalog item, and Description.  As for component inventory units, the view for a particular inventory unit includes an image gallery, log entries, user-defined properties, and assembly members/membership details.

To navigate to the cable inventory listing, select "Cable" from the "Inventory" menu button at the top left of the main CDB portal view.

To add a new unit of cable inventory, select the "Add" button at the top left of the cable inventory listing.  This displays a wizard whose first tab is used to select the appropriate cable type catalog entry.  Selecting "Next Step" displays a review tab where the core properties can be edited.  Selecting "Save" on that tab saves the new inventory unit, and displays the view for that particular inventory unit.

Selecting a unit from the cable inventory listing view displays the detail view for the selected inventory unit.

## Cable Design

The cable design domain extends the machine design domain to include cable plant details.  An item in the cable design domain is a design specifies a cable connection exists between two items (components) in the machine design domain, e.g., a valve controller and valve.  It is important to understand that this is a design concept to model the cable connection.  A unit of cable inventory is used to represent the physical connection once the cable is installed.

Cable design is an evolutionary process.  In early design, when we want to model a connection between two components but are not yet ready to specify the details such as the type of cable to be used, we create a "Placeholder" cable design that simply specifies there is to be a cable connection between the two components.  Later, when we are ready to select a cable type from the catalog for the connection, we assign an item from the cable type catalog to the cable design.  If connectors are defined for both the component and the cable type, we can specify port-level connections in the cable design.  Finally, when we are ready to install the physical cable in the machine, we assign a unit of cable inventory for the particular cable type, and can track that unit throughout its installation and maintenance life cycle.

The core properties for an item in the cable design domain include Name, Alternate Name, Project, Description, the two endpoint components (items in the machine design domain), and the assigned item from the cable type catalog.  Features for port-level connections, virtual cable circuits, and cable bundles will be added in subsequent releases.

To navigate to the cable design listing, select "Cable" from the "Design" menu button at the top left of the main CDB portal view.

To add a new item to the cable design domain, select the "Add" button at the top left of the cable design listing, and select "Cable" from the nested sub-menu.  This displays a wizard whose first tab is used to select the two endpoint components from the machine design domain.  The tab includes two side-by-side machine design hierarchy views.  Select the source endpoint component in the first hierarchy view, and repeat the process to select the target endpoint component in the second.  After selecting the two endpoints, select "Next Step".  On the next tab, enter a name for the cable and select the appropriate project.  Click "Next Step" and on the subsequent tab use the radio buttons to specify whether the new cable design item is a "placeholder" or if a cable type will be selected from the catalog.  Both cases are described in more detail below.

Selecting "placeholder" and "Next Step" displays a review tab for the placeholder cable design.  Selecting "Save" creates the new cable design and displays the detail view for the new cable design item.

Selecting "select from cable type catalog" and "Next Step" displays a tab for selecting the appropriate cable type from the catalog listing.  Navigate through the listing and select the desired cable type.  Selecting "Next Step" displays a review tab.  Selecting "Save" on that tab creates the new cable design and displays the detail view for the new cable design item.

Selecting an item from the cable design listing displays the detail view for the selected cable design item.

## Adding Cable Design from Machine Design Hierarchy View

It is also possible to add a new item to the cable design domain from the machine design hierarchy view.  Navigate to the cable source endpoint component in the hierarchy, and then right-click to open the context menu.  Select the "Cable" menu item, and "Add Cable" from the submenu that is displayed.  This will open a wizard whose first tab is used to select the target endpoint component from a second machine design hierarchy view.  The operation of the wizard is described above.
